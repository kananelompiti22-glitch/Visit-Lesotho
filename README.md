# Visit Lesotho Website

## About the Project
Visit Lesotho is a tourism website designed to promote tourism in Lesotho. 
The website provides information about beautiful places, tourist attractions 
and destinations that visitors can explore in Lesotho.

## Purpose
The purpose of this website is to encourage people to visit Lesotho 
and discover its natural beauty, culture and tourist attractions.

## Website Pages
The website contains the following pages:

- Home: Introduces visitors to the website.
- About: Provides information about Visit Lesotho.
- Destinations: Shows different tourist destinations in Lesotho.
- Gallery: Displays pictures of beautiful places in Lesotho.
- Contact: Provides contact information.
